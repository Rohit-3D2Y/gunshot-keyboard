# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give constructive
feedback, and keep discussions about the project. Harassment, insults or
personal attacks aren't tolerated in issues, pull requests or anywhere else
in this project's spaces.

To report a problem, contact the maintainer privately through
[GitHub](https://github.com/Rohit-3D2Y). Reports are handled confidentially,
and maintainers may remove content or block participants who break these
rules.
