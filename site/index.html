Install

  1. Download GunshotSetup.exe and run it. No admin rights needed.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway. This appears for new apps without a paid code-signing certificate. Every release is built publicly by GitHub Actions from the source code, and you can verify the file against SHA256SUMS.txt.
  3. A red crosshair appears in the system tray (click ^ by the clock). Right-click it to pick a sound and volume.
  4. Uninstall anytime from Settings → Apps.
  1. Download the .dmg for your Mac: Apple Silicon (M1 and newer) or Intel. Not sure? Apple menu → About This Mac: “Chip: Apple M…” means Apple Silicon.
  2. Open it and drag Gunshot into Applications.
  3. First launch: right-click Gunshot → Open, or allow it under System Settings → Privacy & Security → Open Anyway.
  4. Allow Input Monitoring for Gunshot when asked, then quit and reopen it. macOS requires this for any app that reacts to typing.
  5. The crosshair lives in the menu bar. Toggle with Ctrl+Option+G.

FAQ

Is it safe? Isn't listening to my keyboard what keyloggers do?

The app needs to know when you press a key, which is the same permission every keyboard-sound app needs. The difference is what happens next: Gunshot plays a sound and forgets the key. It never writes keys anywhere and has no network code at all. The entire source is public, so anyone can check, and releases are built by GitHub from that exact source.

Why does my antivirus or SmartScreen warn about it?

New, unsigned apps that listen to the keyboard can trigger warnings. You can verify your download with the SHA256SUMS.txt attached to each release, or build it yourself from source.

Can I add my own sounds?

Yes. Drop a folder of .wav files into gunshot/packs/ and it appears in the menu. See the sound pack guide, or request a sound.

How do I turn it off quickly?

Press Ctrl+Alt+G (Mac: Ctrl+Option+G). The crosshair turns grey.
